Convenciones y notas

  • Se conserva la capitalización exacta del SQL, incluida ID.
  • BIT(1) representa un indicador binario; el DDL no siempre especifica su semántica funcional.
  • ON DELETE CASCADE puede propagar eliminaciones físicas, sujeto a triggers y motor.
  • ON DELETE RESTRICT bloquea la eliminación del padre referenciado; SET NULL conserva el producto sin categoría.
  • Una descripción no implica una validación si no existe una restricción declarada.
  • El campo tb_order_items.subtotal es generado; tbd_order_details.subtotal es un valor almacenado común.
